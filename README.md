# ArtPayments Web — PWA MVP

Работающее демонстрационное PWA-приложение для iPhone. Без реальных банковских интеграций, NFC-провижининга и оплаты.

## Бесплатная публикация через GitHub Pages (только с iPhone)
1. Создайте бесплатный аккаунт на github.com.
2. Создайте **публичный** репозиторий, например `artpayments-web`.
3. Загрузите **содержимое** папки `ArtPayments_Web` в корень репозитория: `index.html`, `app.js`, `sw.js`, `manifest.webmanifest` и папку `icons`.
4. Откройте **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save**.
5. Дождитесь публикации. Адрес обычно `https://USERNAME.github.io/artpayments-web/`.
6. Откройте адрес в Safari на iPhone → Поделиться → На экран «Домой» → Добавить.

**Важно:** GitHub Pages — публичный статический хостинг. Не загружайте туда секреты, банковские ключи и пользовательские данные. В MVP данные хранятся только в localStorage браузера; при очистке данных Safari они удалятся. Приложение демонстрирует привязку банка и блокировку только визуально.

## Локальная проверка на компьютере (необязательно)
`python3 -m http.server 8000` в папке проекта, затем открыть http://localhost:8000.
